Extractor prompt

Send a PDF to any capable model with this prompt. It returns JSON this app reads directly. Edit it if your papers have quirks — your version is saved here.

Your saved prompt predates figure slots
The extractor can now leave an empty figure slot in the JSON, which this app draws as a one-tap upload panel exactly where the picture belongs. Your edited copy never asks for one. Restore the default, or paste section 9 of it into your version.

      
      

        
        
      

      
How the loop works

      

        
1 — Split the PDF into batches of ~25 questions if it's long. Models get sloppy past that.

        
2 — Paste this prompt, attach the PDF, ask for JSON only.

        
3 — Save the reply as batch-name.json, or copy it straight into Import.

        
4 — Check the key conflict filter in the bank: those are questions where the model disagreed with your paper's answer key. Decide those yourself.

Data & storage

      
Everything lives in this browser. Backups, exports and restores are on the Import screen; the two buttons here destroy data and cannot be undone.

      

      

        
        
        
      

      


      
      

      
Cloud sync

      
Point Nidus at a private GitHub repository and it keeps a second copy there. Changes from your other devices are merged in, never overwritten — answers, notes and sessions are treated as append-only logs, and every save is a commit, so any earlier state is recoverable from the repository's history.
